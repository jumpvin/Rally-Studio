## Current Phase 5 decisions
- The website is the primary editing workspace.
- Editing is intentional through Edit Mode.
- Quick content edits should be nearly frictionless and can publish immediately.
- Small live changes are logged and reversible through history/versioning.
- Editing depth progressively reveals more controls: quick content, component options, page/composition editing, then full design-system controls.
- Standard clients receive constrained editing capabilities; advanced users may receive broader Studio access.
- Global design defaults such as typography, color, spacing, radius, and shadows remain centralized and inherited by components.
- The context sidebar changes according to the selected object or active lens.
- Comments/conversations are managed in the sidebar; when Comments mode is active, contextual pins appear on the website and link to the same conversations.
- The website remains visually clean when feedback lenses are inactive.
- Pages are the default navigation model.
- Alternative explorer views may expose components and their usage/instance locations across the site.
