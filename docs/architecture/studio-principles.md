# Rally Site Studio Principles

1. Opinionated by default; flexible by exception.
2. Automation prepares; people approve.
3. One clear next action.
4. Progressive disclosure over information overload.
5. Studio captures Rally expertise so every future website can benefit.
6. The client relationship continues after launch.
7. Assets persist; work happens through projects.
8. Everything starts local; everything shared is intentional.
9. Simple changes should be immediate; safe changes should be reversible.
10. Reveal complexity only when the user asks for it.
11. The website is the workspace; panels change the lens through which it is viewed.
