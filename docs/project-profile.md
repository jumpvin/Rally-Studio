# Rally Site Studio Project Profile

## Product
Rally Site Studio is the Rally website production platform used to design, assemble, deploy, and maintain Rally websites.

## Repository
`jumpvin/Rally-Studio`

## Framework
Rally Development Framework `0.3.9-dev.16.4`.

## Current lifecycle state
Discovery is active. Phase 5 (Editing) is in progress. Production implementation is not authorized until Discovery is completed and Architecture creates implementation milestones.

## Architecture Chat responsibilities
Product Discovery, Architecture, UX, Studio Workflow, Design System, Blueprint System, Composition System, Starter Packages, Website Assembly, Roadmaps, Reviews, and Milestone Planning.

## Builder boundary
The Builder implements approved milestones only. Architecture decisions and discovery remain authoritative here and must be synchronized into repository documentation before implementation begins.
